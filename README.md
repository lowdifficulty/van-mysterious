# Van

A fictional muse site — midnight cinema and games. Next.js App Router, TypeScript, Tailwind.

Local: [http://localhost:3003](http://localhost:3003)

```bash
npm install
npm run dev
```

The archive stays locked until a visitor reads Policies, agrees, and confirms they are 18+ (name, email, date of birth). Session is an encrypted `iron-session` cookie. Use **Reset gate** to clear it.
